# 🧠 心理健康助手

基于 RAG（检索增强生成）技术的心理健康智能问答系统。

## ✨ 功能特点

- 💬 智能对话：基于 DeepSeek 大模型，提供心理健康支持
- 📚 RAG 检索：从权威文档中检索信息，回答更准确
- 🆘 紧急求助：自动检测敏感词，提供求助热线
- 📋 历史记录：保存对话历史，支持多会话管理
- 📤 导出功能：支持导出聊天记录为 CSV 文件

## 🛠️ 技术栈

- Python + Streamlit
- LangChain + RAG
- DeepSeek API
- Chroma 向量数据库
